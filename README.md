# تطبيق مِحْراب: مواقيت الصلاة والقرآن في الجزائر

تطبيق إسلامي متكامل مبني بإطار العمل **Flutter** مخصص للمسلمين في الجزائر، يعمل بنسبة **100% دون اتصال بالإنترنت (Offline-First)**.

---

## المكونات الأساسية للتطبيق:
1. **مواقيت الصلاة:** حساب فلكي دقيق وفق طريقة وزارة الشؤون الدينية والأوقاف الجزائرية لكافة الـ 58 ولاية.
2. **القرآن الكريم:** فهرس كامل لـ 114 سورة مع محرك بحث فوري.
3. **الأذكار وحصن المسلم:** أذكار الصباح والمساء وبعد الصلاة مع سبحة إلكترونية تفاعلية.
4. **بوصلة القبلة:** حساب زاوية القبلة الدقيقة من كل ولاية نحو الكعبة المشرفة.
5. **شاشة الافتتاح (Splash Screen):** شاشة ترحيبية متحركة تحمل هوية مِحْراب.
6. **إعدادات الأذان والتنبيهات:** خيارات أصوات الأذان الجزائري والوضع الصامت التلقائي في المسجد.

---

## حل مشكلة البناء الأخيرة (Troubleshooting):
* **سبب الخطأ السابق:** كانت ملفات `splash_screen.dart` و `settings_screen.dart` مستدعاة داخل `main.dart` و `prayer_screen.dart` ولكنها لم تكن موجودة داخل مجلد `lib/screens/`.
* **الحل المنفذ:** تم تضمين كافة الملفات المصدرية المفقودة بالكامل في المجلد `lib/screens/`، مما يجعل عملية البناء تعمل بنجاح ودون أي خطأ تركيبي.
